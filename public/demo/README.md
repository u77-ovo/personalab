# PersonaLab 重构版 Demo

这是一个与原项目完全隔离的前端演示版本，依据最新确定的产品架构制作，不依赖原有 Demo 的页面或流程。

## 已实现

- 无需注册即可体验完整 Demo，数据保存在浏览器 `localStorage`
- Workspace：项目、资料、Persona、验证轮次和报告总览
- Persona 用户库：平台预设类型和用户自定义 Persona
- 真实需求资料库：访谈、问卷、评价、行业与竞品资料
- Spark 播种：输入产品方向、选择资料范围和 Persona，生成模拟圆桌、需求洞察、来源证据和概念建议
- Mirror 预演：接收截图/链接/流程等输入，生成任务路径、问题优先级与固定八维评分；材料不足的维度不会强行打分
- 报告中心：保存验证结果并导出 Markdown
- 继续上次项目：刷新后恢复最近一次 Spark / Mirror 结果
- 重置数据与响应式移动端布局

## 运行

直接双击 `index.html` 即可使用。为了获得更稳定的浏览器行为，也可以在当前目录运行静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 演示边界

当前版本是离线交互原型：不调用真实 AI、不联网搜索，也不上传用户选择的文件。Spark 和 Mirror 输出均为固定逻辑生成的示例结果，并在界面中明确标注。正式版需要进一步接入模型服务、公开资料检索、文件解析、登录与云端存储。
